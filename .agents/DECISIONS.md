# 关键决定

仅记录影响后续开发的决定、理由和替代方案。

2026-10-16｜工作空间采用每空间独立 SQLite + App Support/Velora/workspaces.json 原子目录；旧数据库原位登记。切换保存失败、目标丢失、目录写入失败均不替换活动 model。删除仅移除列表，保留数据库及删除元数据；至少留一个空间。AI/外观/备份目录等保持应用级，备份时间按空间记录。

2026-10-21｜公式与 Markdown 采用独立 WKWebView 预览，编辑继续用原生文本视图；KaTeX/Marked/DOMPurify/highlight.js 与字体固定版本随应用打包，CSP 禁止远程子资源，Markdown 先清理再渲染公式。保持离线与原有富文本编辑器的撤销/输入法行为；LaTeX 范围为数学公式子集，完整 TeX 编译与排版导出另行实现。

- 2026-10-21：HTML/PDF 导出复用本地 WK 排版；Word 用 MathML 转 OMML 保持公式可编辑。PDF 导入保留原始文件，文字提取作为独立操作。自有格式结构元数据只在可见内容校验一致时恢复，防止忽略外部编辑。XMLParser 回调内不得重入解析公式，先收集再转换。

- 2026-10-21：使用 en/zh-Hans.lproj 与 L10n 本地化，语言偏好保存在 appLanguage；类型及协议标识保持原值。备份采用 DEFLATE ZIP，清单携带版本和数据库 SHA-256；SQLite online backup 后切换快照为 DELETE journal 以独立携带全部提交内容。恢复不覆盖活动数据库，而是验证后发布新工作空间，失败保留原数据与目录配置。

- 2026-10-22：依用户要求，文件默认导入改为多个内容块：PDF后台逐页提取富文本，按相对字号推断标题并识别列表；无文字层页面保留图片并用本地Vision中英文OCR附加可编辑文字。Markdown/外部HTML使用原生块解析器，TXT按非空行分块；JSON及自有格式元数据仍保留已有结构。取代此前“PDF默认保存原件”的决定，不自动迁移已存页面；旧PDF块仍支持原件预览/导出。PDF复杂多栏、表格、公式和文字页图形不能保证还原，不宣称完整保真。

- 2026-10-23：PDF转换先按行几何及字体/代码语法识别结构，代码不走Markdown内联解析；PDFKit可能以普通字体替代等宽字体，使用相邻行平均字宽和相对位置辅助恢复。嵌套引用/列表等原生块不能表达的结构保留为局部Markdown块，避免为了全原生拆块而丢失层级；Word/RTF/HTML代码空白按源码保留。没有用户样本时以实际绘制的PDF、外部Word及HTML/RTF夹具验证，不宣称所有PDF保真还原。

- 2026-10-23：原生编辑器输入确认和外部内容重置使用不同信号：单块contentRevision显式标识slash转换，解决模型值空->命令->空合并刷新后无法区分的情况。命令一次SQL更新类型/正文/选项，按块串行，flush等待转换完成，防止命令后的即时输入被初始正文覆盖。普通输入不增加revision，维持低刷新开销。

- 2026-10-23：slash菜单不能用行内offset overlay实现，LazyVStack/原生编辑器的命中边界可令可见菜单无法点击。改为附属于编辑窗口的非激活NSPanel，canBecomeKey=false且接受首次鼠标，保留编辑器键盘输入；通过锚点与滚动通知定位，生命周期统一关闭。此类问题必须包含独立宿主窗口的真实AppKit鼠标与键盘事件回归，不能仅用模型转换测试判定修复。

- 2026-10-23：表格尺寸独立为TableLayout，SQLite v5 table_layout列及TransferBlock元数据保存，二维字符串正文保持兼容。拖拽本地预览、松开合并最新模型后防抖保存，防止连续宽高操作以旧快照覆盖另一轴；增删行列按结构保留尺寸。备份校验共用当前schema版本上限，迁移变更须验证备份恢复。

- 2026-10-23：内部剪贴板区分文字选区与整块：代码选区显式text-selection标记，整块用TransferBlock JSON专有类型，避免根据正文语法猜测类型或丢语言/缩进/表格尺寸。预览JS传结构化复制消息。SwiftUI onDrag不提供结束回调，页面拖拽用common-mode鼠标状态监测兜底清理，放下/打开页面/销毁共用finish。

- 2026-10-23：标题转换需同步NSTextView基准字体和typingAttributes，不能只改已有attributed text；空标题否则仍以正文插入并生成显式小字号。转换为语义标题时移除原文字号覆盖，保留其他局部样式；原生选区减去Markdown标记长度，避免已有文字前转换后光标跳尾。

- 2026-10-23：侧栏展开状态是每工作空间的本机界面偏好，以workspace ID索引UserDefaults中的折叠页面集合，不写入页面数据库。搜索可临时展示匹配路径但不改集合；普通页面数据刷新不自动reveal，避免覆盖用户折叠意图，仅主动选择页面展开祖先。

- 2026-10-23：原生焦点是跨块请求，派发时既要读取coordinator当前parent，也必须核对WorkspaceModel最新请求ID，不能只凭旧视图快照或本地lastFocusRequest；否则旧编辑器的延迟任务会抢回光标。只有实际获得第一响应者才消费请求，视图挂载窗口后补发，确保惰性构建的长文下方新块可聚焦。

- 2026-10-23：原生表格正文继续二维字符串数组，但单元格是可见文字而非Markdown。TableLayout兼容JSON字段cellsArePlain标记新内容，缺省false仅用于旧整格代码标记显示兼容；新Markdown/HTML导入先解码inline语法，编辑及Word导入标记为原样。导出Markdown需转义实际符号，尺寸重置不能重置文字模式，避免真实反引号被误吞。

- 2026-10-23：选区格式浮窗在字体/颜色菜单动作中不得更换NSPopover.contentViewController或同步强制布局；真实崩溃证实会触发SwiftUI/AppKit材质递归直到栈耗尽。每个编辑器复用一个host和ObservableObject样式状态，菜单回调返回后更新状态，校验最新样式和生命周期；样式变化不能重新创建菜单所在视图树。

- 2026-10-23：样式复制采用独立命名pasteboard中的InlineTextStyle有效视觉快照，而非正文剪贴板/富文本内容；默认值显式解析为实际字体字号和traits，避免跨标题/正文基准继承错误。混合选区以首字符为样本，粘贴只替换视觉属性，保留目标link/code语义，沿用原格式撤销和持久化流程。
