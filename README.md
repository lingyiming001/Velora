# Velora

Velora 是开发中的 macOS 原生、本地优先知识工作台：用页面与块完成写作，用链接与搜索找回知识，用结构化视图组织项目。当前仓库已有可运行的**早期竖切片**；设计文档描述的是目标方案，尚未全部实现。

- 设置支持简体中文、English 和跟随系统；切换即时生效，不改变文档内容。
- 设置 → 存储与备份可在所选目录的 `backup` 子目录生成所有工作空间的单个 ZIP 备份，一次恢复全部空间，兼容旧版单空间 ZIP。每个空间使用独立文件夹；选择统一存储位置会自动加载 `Workspaces` 下已有空间，包含页面、块、回收箱及内嵌资源，保留原文件；上限 512 MB。

## 已实现的早期竖切片

- SwiftUI 主窗口、侧边栏、页面创建/子页面创建/回收箱和标题编辑。
- AppKit `NSTextView` 文本块输入；正文、三级标题、无序/有序列表、待办、折叠、引用、提示、分割线、图片/音视频、文件链接、书签、代码、简单表格、页面目录，共 24 种块；支持分类 `/` 菜单搜索块类型、方向键选择、回车转换与 Esc 关闭；文本块随内容增高，代码块支持预设/自定义语言和折叠（状态本地保存），点击页面末尾提示新增内容，400 ms 空闲自动保存。
- SQLite 本地存储、按标题或正文搜索、浅色/深色/系统外观设置。
- 两项 SQLite 持久化与归档搜索测试。

编辑器仍是验证原型：跨块选区、拖拽排序和版本历史尚未实现；不可把当前构建用于重要资料。

## 设置与应用控制

设置包含主题/强调色、编辑字号、所有工作空间统一存储迁移、备份位置、手动/每日备份、AI 连接、MCP 与语音。
主窗口工具栏或 `⌘J` 打开助手；指令先预览再执行。支持兼容 Chat Completions 的模型服务；密钥存系统钥匙串。
MCP 默认关闭，启用后仅监听本机且默认只读；允许写入后，外部客户端可以操作页面，并用 `append_document` 将 Markdown/HTML/纯文本追加为可编辑块，或用 `import_document` / `import_file` 新建与导入文档。支持 Streamable HTTP；设置可复制 stdio 桥接配置（需要 Python 3）。[接入步骤与调用示例](deploy/MCP.md)。
语音由系统识别，用户主动录音，默认仅设备识别；首次需要麦克风和语音识别授权。
完整说明、连接配置与已知边界见 [设置与应用控制](docs/Settings-and-Automation.md)。

## 页面整理与回收箱

- 侧边栏按页面树展示，支持展开/折叠、筛选、重命名和新建子页面。
- 将页面拖到另一页面上，使其成为目标页面的子页面；目标高亮并展开。子页面行有移出一级按钮；拖到侧边栏底部可移到顶层。上下排序使用页面菜单的上移/下移。
- 菜单栏提供新建页面（⌘N）、搜索页面（⇧⌘F）、重命名（⇧⌘R）、移动到（⌃⌘M）及全部展开/折叠；弹窗操作期间禁用页面命令。
- 页面菜单提供上移、下移、“移动到…”和移到顶层；移动目标支持搜索，并排除自身及后代。
- 删除页面先进入回收箱；恢复保留同批删除的子页面，先前单独删除的子页面仍留在回收箱。
- 原父页面仍在回收箱时，恢复的页面移到工作区顶层。永久删除与清空回收箱均需确认。
- 旧版本归档页面会出现在回收箱；旧记录没有删除批次，逐页恢复，不推断历史批次。

## 块编辑

- 在正文块输入 `/` 可打开按基础块、媒体与链接、进阶块分类的菜单，支持中英文类型名搜索、方向键选择、回车或 Tab 插入。常用别名包括 `/text`、`/h1`、`/h2`、`/h3`、`/list`、`/toc`、`/pdf`、`/math` 和 `/md`；所有块类型均可用其英文类型名插入。命令执行后清除查询并聚焦可编辑内容，表格默认创建 2×2 网格并聚焦首格。
- 折叠块以首行为标题，换行输入正文，折叠后保留标题；状态本地保存。
- 侧栏按工作空间记住页面树展开/折叠状态，重启或切换空间后恢复；“页面”标题右侧菜单可全部展开或全部折叠。主动跳转到隐藏子页面时仅展开其祖先路径，普通刷新不改变手动折叠。
- 输入 `/image` 并按回车或选择图片命令，会直接打开 URL／本地图片选择器；取消后保留可继续选图的空图片块。图片、音视频、书签和文件块支持 HTTP(S) 链接；音视频需要系统播放器支持的直接资源地址，不支持任意视频网站嵌入或本地文件上传。
- 选中文字后，浮动工具条“样式”菜单提供复制样式和粘贴样式，快捷键分别为 `⌥⌘C` / `⌥⌘V`。可跨文字块应用字体、字号、粗斜体、下划线、删除线、文字色和高亮，保留目标文字、链接与选区外格式，支持撤销/重做。混合样式选区以首个字符为样本；样式使用独立剪贴板，不覆盖已复制的正文。
- 正文按 `Enter` 在光标处分成两个块（选中文字会被替换），按 `Shift+Enter` 在块内换行；空正文按回车继续创建正文块。标题按 `Enter` 进入正文，列表/待办按 `Enter` 续项、空项回车退出，`Shift+Enter` 块内换行；标题开头回车在上方留出空正文并保留标题。引用、提示、警告、成功提示及折叠块保留多行，末尾空行再按 `Enter` 退出到下方正文，`Shift+Enter` 始终块内换行。代码/公式/Markdown 源码及表格单元格保留原有多行输入；源码编辑器可用 `Shift+Enter` 跳出。媒体地址按 `Enter` 进入下方正文，选中非文本块后按 `Enter` 在其下方继续书写。
- `⌘F` 在当前文档内查找标题、正文、列表、引用、代码和表格单元格文本，显示匹配计数及临时高亮；`Enter` / `⌘G` 跳到下一项，`Shift+Enter` / `⇧⌘G` 返回上一项，首尾循环，`Esc` 关闭。查找随当前内容更新，切换页面时关闭；`⇧⌘F` 仍为全局页面搜索。单独输入 `f` 不影响编辑。
- 查找栏左侧箭头展开替换，也可用 `⌥⌘F`。支持替换当前项、当前文档全部替换，以及留空删除匹配文字；替换按字面文本执行，保留块类型、未匹配文字格式和表格尺寸，新文字沿用匹配首字符的格式。提供“撤销替换”恢复最近一次操作；若受影响内容已被后续编辑则禁用该撤销，避免覆盖新修改。
- 正文开头按 `Backspace` 与前一普通文本块合并，保留文字与行内格式，光标回到连接处。列表、标题、引用或提示块开头先转为正文；遇到图片、表格、代码等特殊块只选中前块，避免把文字拼进媒体链接或源码。
- 正文行首输入 `# `、`## `、`### ` 自动转换为一至三级标题，去掉标记并保留标题文字；粘贴 Markdown 标题也会生成标题块。从代码选区复制的原样文字不触发标题转换。已有文字前输入 `# ` 同样生效，转换后保持光标位置及标题输入字体；也可用 `⌘⌥1`、`⌘⌥2`、`⌘⌥3` 将当前文本块转换为对应标题。
- 简单表格首行为表头，可编辑多行单元格、增加行列；“删除 → 删除行/删除列”可指定任意行列，单元格右键菜单也可删除所在行或列，至少保留一行一列。删除时保留其余单元格和对应行高列宽。拖动单元格右边缘调整整列宽度、下边缘调整整行高度，支持重置尺寸；尺寸会随页面保存，并保留在 JSON 与空间备份中。内容继续以 JSON 存入块正文，旧表格自动使用默认尺寸。Markdown/HTML 表格的行内代码、粗体等标记转换为可见文字，避免方法名两侧出现多余反引号；已有表格兼容显示旧的整格代码标记，手工输入的真实反引号按普通内容保留。
- 页面目录自动收集三级标题，点击跳转到对应标题。
- 表格采用浅色网格与青色单元格选中框；右侧 `+` 加列，底部 `+` 加行，右下角 `+` 同时增加行列，支持横向滚动。连续操作读取最新内容，保留已有单元格和行高列宽。
- 聚焦表格时，上边框和左边框显示圆形列/行操作柄，菜单删除对应行列，至少保留一行一列；失焦隐藏操作柄和加行列入口，不占用额外菜单列。侧栏当前文档的浅灰聚焦底色扩展至接近整行，文字与右侧菜单的位置保持稳定。
- 侧栏当前编辑文档使用浅灰圆角聚焦背景，仅该文档显示右侧三个点；其他文档仍可通过右键操作。页面“移动到…”（`⌃⌘M`）可选择其他工作空间，将文档及未删除的子页面移到目标空间顶层，保留内容与格式；目标保存成功后源文档移入原空间回收箱，可恢复。移动后停留在当前工作空间，通过左上角空间菜单切换查看。外部文件/媒体链接保留原地址，不搬动原始文件。
- 代码块采用独立卡片，按内容紧凑增高并在删行后收缩；标题栏“代码显示设置”可分别切换左侧行号和顶部行数统计，与设置页同步并记住选择；支持轻量词法高亮、复制反馈、语言菜单与折叠；并非完整语言解析器。选中代码里的文字复制，在 Velora 内粘贴为原样文字；使用复制代码按钮或复制整个块，在 Velora 内粘贴保留代码块、语言及缩进。Markdown 预览中的代码也遵循相同规则。
- 代码语言按常用、网页与样式、数据与配置、脚本与其他分组，覆盖 Python、JavaScript/TypeScript、Java、C/C++/C#、Go、Rust、Swift、SQL、Shell/PowerShell、HTML/CSS、JSON/YAML/TOML、Dockerfile 等。识别 `py/js/ts/cpp/cs/sh/yml` 等缩写；按语言处理注释、字符串、关键字、数字及标记，继续支持自定义语言和纯文本。
- 新增 LaTeX 数学公式与 Markdown 文档块，输入 `/latex`、`/math` 或 `/markdown` 插入。公式支持分式、积分、矩阵、多行；Markdown 支持标题、表格、代码高亮与复制、Mermaid 流程图，以及 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 数学公式；可切换源码编辑和预览。
- 警告块与成功提示用于醒目标注。块菜单支持复制内容、上移/下移；块左侧 `+` 和 `/` 菜单支持插入块。主窗口右侧工具栏仅保留 AI 和导出，左侧保留插入块、页面宽度和文档导航（顶部/底部、查找及全选）；搜索与新建页面仍可通过菜单及快捷键使用。
- 渲染使用随应用打包的 KaTeX、Marked、Mermaid、DOMPurify 和 highlight.js，运行时不加载远程脚本；第三方许可及精确版本在 `App/RenderAssets/`。LaTeX 为数学公式子集，不编译完整 TeX 文档。
- 粘贴结构化 Markdown 或 HTML 时会拆分成可独立编辑的标题、正文、列表、表格、代码、Mermaid 和公式块；从 ChatGPT 粘贴 KaTeX 时优先恢复原始 TeX，避免视觉文本中的反斜杠与组合字符污染公式。`⌘A` 可选择全文块，`⌘C` 同时复制 Markdown 与 HTML。 ChatGPT 等来源的行内代码保留灰色底色、粗体；粘贴时结合明确的横排布局或剪贴板同一行文本保留短标签同行关系，独立段落仍分块，不复刻网页任意 CSS。
- 在单块内拖动仍按文字选择，拖到另一块后转为整块范围选择，可混选标题、正文、列表、代码、图片与其他块，并在页面边缘滚动扩选。`Shift` 点击选择连续范围，`⌘` 点击增减单块；选中后可 `⌘C` 复制、`⌘X` 剪切、`Backspace` 删除，`Esc` 取消。复制保留块类型与原有顺序。
- Markdown/JSON 保留公式源码；HTML/PDF 使用与预览相同的渲染器输出排版公式，Word 输出可编辑的 Office 数学公式。JSON 保留全部块类型和选项。自有 HTML/Word 文件在内容未修改时可恢复完整块结构。
- 导入 Markdown 和外部 HTML 会拆分成标题、正文、列表、待办、代码、公式、表格与图片块；代码保留缩进和连续空行，多行引用合并，复杂嵌套列表/引用保留为独立 Markdown 块。Word 代码样式与 RTF 等宽段落保留前导空格、Tab 和空行。PDF 默认在后台逐页解析为可编辑文字块，按字号推断标题，并结合等宽字体、行宽、代码语法和相对位置识别代码、恢复缩进；缩进引用合并为引用块；无文字层的扫描页保留图片，并尝试本地中英文 OCR。PDF 自动解析最多 500 页，解析后内容最多 100 MB；复杂多栏阅读顺序、表格、公式及文字页中的图形暂不保证完整还原。已有 PDF 原件块仍可预览和保真导出，不自动修改已有页面。外部 Word 的复杂样式和公式不保证完全还原。
- 当前未实现数据库视图、嵌套子块或同步块。

## 产品边界

- 首发对象：重视离线、速度和键盘效率的个人知识工作者。
- MVP：单用户、单设备、页面树、原生块编辑、全文搜索、附件、Markdown 导入导出、本地备份。
- V1.0：数据库及表格/列表/看板/日历视图、模板、双向链接、版本历史。
- V2.0：iCloud 同步、关系属性、AI 功能。团队实时协作另行验证商业需求。

所有版本标签均为**规划假设**，需在发现阶段验证。具体范围见 [产品概览](docs/01-Product-Overview.md) 与 [PRD](docs/02-PRD.md)。

## 代码目录

工程使用一个 App target，按职责组织为 `App/`（入口）、`Domain/`（模型）、`Data/SQLite/`（本地数据）、`Features/`（界面和状态）及 `Tests/`。实际目录和新增文件放置规则见 [项目目录结构](docs/08-Project-Structure.md)。新增 Swift 文件后运行 `scripts/generate_project.rb` 更新工程。

## 在 Xcode 中运行

打开 `Velora.xcodeproj`，选择共享 Scheme **Velora** 和 **My Mac**，按 `⌘R` 运行；`⌘U` 运行测试。

- App target：**Velora**；图标在 `App/Assets.xcassets/AppIcon.appiconset`，General 中选择 AppIcon。
- Info 页管理显示名、版本、分类及麦克风/语音识别用途说明；`App/Info.plist` 保留局域网访问配置。
- `App/Velora.entitlements` 启用 Hardened Runtime 所需的音频输入权限；系统授权仍在主动录音时申请。
- 默认使用本机 ad-hoc 签名（Sign to Run Locally），无需开发者团队；发布时在 Signing & Capabilities 配置自己的团队及分发签名。
- 当前关闭 App Sandbox，以兼容已有自选存储目录、备份及本机 MCP 服务。发布沙盒版本需另行实现安全作用域文件访问。
- 工程生成脚本保留上述配置及 Run/Profile 的 App 可执行文件设置。

## 拟议开发环境

- Xcode 27、Swift、SwiftUI + AppKit，最低 macOS 14（暂定，仍需目标设备验证）。
- SQLite 经轻量封装访问；当前搜索使用参数化 `LIKE`，`FTS5` 是后续性能阶段目标；无网络运行时依赖。
- 工程：`Velora.xcodeproj`。构建：`xcodebuild -project Velora.xcodeproj -scheme Velora -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO build`。
- 测试：`xcodebuild -project Velora.xcodeproj -scheme Velora -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO test`。本机 2026-10-13 已通过。
- 工程可用 `scripts/generate_project.rb` 重建，需本机安装 `xcodeproj` Ruby gem。

- 块左侧 `+` 可按类型直接插入；块菜单支持“创建块副本”，多选后底部工具栏可批量创建副本。副本按原顺序插在最后一个所选块之后，并保留文字格式、代码语言、待办状态和表格尺寸；本地媒体保留原文件引用。类型转换限于兼容正文类型，保留代码转正文入口，避免把表格 JSON 或媒体地址误转成其他结构。

- 侧栏按页面元数据建立层级索引，复用筛选/折叠结果，正文输入与自动保存不重建页面树；表格按块快照解析单元格，滚动及悬停时复用。新建页面通过同一事务保存首个正文块，直接显示并聚焦，保留已访问页面缓存。

- 侧栏页面菜单和右键菜单提供“复制页面”：复制当前页面及未删除的子页面，保留块类型、格式、代码设置、待办状态和表格尺寸。副本位于原页面下方，名称使用递增数字（例如“页面 1”“页面 2”，再次复制不叠加文字），完成后自动打开。页面和块采用独立ID，外部媒体/文件继续引用原地址。复制前保存待写入正文，整个页面树在同一事务中写入，失败完整回滚。

- 图片块以无外层卡片的方式直接展示，按原比例紧凑展示，小图不放大，大图最多约640×420并随正文宽度缩小，不裁切；悬停或选中显示更换按钮，右键及块菜单也可更换。空图片保留选择入口。

- 图片悬停或选中时，拖动右侧手柄可等比例调整正文中的宽度；尺寸会随页面保存，并保留在页面/块副本、JSON 和空间备份中。右键或块菜单可恢复默认紧凑大小。双击图片或点击放大图标打开大图预览，支持缩放滑杆、放大/缩小、100%、适合窗口和横纵滚动；Esc关闭预览。图片原文件不改动。

- 粘贴 Markdown/HTML 有序列表时保留原始起始编号（含 HTML `ol start` 与 `li value`），例如正文、代码、项目列表之后的 `2. Prompt` 仍显示为 2；相邻普通列表继续自动编号，连续 Markdown `1.` 标记按列表递增。复制列表中间项会带上当前显示编号。Markdown、HTML、TXT、Word、PDF 与 JSON 共用编号语义。旧内容可在有序块菜单选择“接续前一编号”或“从 1 重新编号”，不自动改写已有文档。

- 图片悬停工具条/右键菜单，以及图片、音视频、附件和原件PDF的块菜单提供“保存到本地…”，音视频/附件也可从来源栏保存。内嵌资源保存原始字节，本地引用另存副本，网络直链后台下载后选择位置；可取消，完成后可在Finder查看。重名由系统保存窗口确认覆盖，写入采用同目录暂存后原子替换，失败或取消不覆盖已有文件。仅保存资源副本，不改页面来源链接；视频网页和HLS/DASH播放列表不作为完整音视频下载。

- EPUB 电子书：在“导出格式”选择 EPUB，当前页（可含子页）或整个工作空间输出为单个 `.epub`。页面按侧栏树顺序作为章节，目录包含页面层级和正文标题；正文、列表原编号、代码、表格、粗体与行内代码保留。图片打包为 PNG 以便离线阅读，PDF 块转为页图；图片加载失败会终止导出并保留已有目标文件。公式与 Mermaid 暂保留源码，音视频及附件仅保留网络链接，未提供 EPUB 导入。书籍内容上限 100 MB。

- 从 ChatGPT 网页/客户端粘贴含内联 SVG 的内容时，支持路径、圆形、矩形等静态线框图标，转换为小尺寸离线 PNG 图片块，避免图标丢失；不执行 SVG 脚本、外部资源或网页 CSS。源剪贴板必须包含图标 HTML，纯文本复制无法恢复未携带的图标；复杂 SVG 文字图表/外部 sprite 不在此支持范围。

- ChatGPT 图文卡片若在剪贴板中以 `images.openai.com/static-rsc-*` 图片链接提供，粘贴时恢复为图片块，不再当作来源网页标题链接；链接包裹的普通图片也保留为图片。粘贴及导入时会下载网络图片并嵌入文档数据库，随JSON与空间备份保存，后续显示不依赖原图片地址；保留图文顺序，暂不复刻左图右文卡片布局。

- 网络图片本地化：新粘贴、文件导入、MCP导入及从URL选图自动下载并存入文档；普通网页/书签链接不变。单张上限12 MB，导入内容上限100 MB，下载/校验失败不提交部分导入内容。已有图片可右键“转为文档内本地图片”，或通过顶部“文档导航 → 将本页网络图片转为本地”批量转换；不需要另选文件路径。

- 紧凑图文卡片：粘贴可识别的“单张图片＋短标题＋说明/关键词”分组时，保留为左侧76pt缩略图、右侧可编辑文字的一体卡片。图片仍嵌入文档离线保存，复制、JSON与空间备份保留卡片。已有独立图片可右键“与下方文字合并为图文卡片”，合并紧随其后的标题/说明/关键词；不自动修改已有页面。HTML/PDF采用卡片样式，Markdown/Word/EPUB保留顺序内容。

- Python 原始代码复制：代码块自身复制按钮提供的多行纯源码（含导入/定义和明确Python语法）可自动生成Python代码块，保留换行/空行/缩进；不把混有说明的整篇文章当代码。HTML无语言标签时支持邻近`.py`文件名上下文；检测到来源已将两条from/import语句拼在同一行时，保留原文并显示重新使用来源“复制代码”按钮的警告，不猜测重排源码。

- 代码块标题栏的魔杖按钮（或右键“修复换行…”）可修复已粘成一行的代码。先并排预览原文和可编辑建议，点击“应用修复”后才替换；简单 import/赋值粘连、import/属性遍历打印可生成本地建议。复杂代码可主动点击“使用 AI 生成建议”，只发送当前代码块给 AI 设置中的文字对话模型。替换时检查非空白字符及普通/三引号字符串内容未改动，生成期间若原块内容变化则拒绝覆盖。建议仍需检查，尤其是 Python 缩进；不执行代码，也不保证恢复原作者的排版或含义。

- Chrome ChatGPT 普通选区复制丢代码换行：提供可选的[浏览器复制助手](deploy/chrome-copy-helper/README.md)，在用户选中内容后按 ⌘C 时将网页 CodeMirror 代码行转为含真实换行的 HTML/纯文本，再交给 Velora 正常粘贴；覆盖 Python 与 Plain Text、正文混排、部分选区和空行。仅作用于 chatgpt.com，不访问网络或读取全局剪贴板；需用户授权加载浏览器扩展。网站“复制回答”按钮可能绕过 copy 事件，不在此助手覆盖范围。

- 页面标题支持选中文字后 `⌘C`，或右键“复制标题”复制完整名称；进入标题编辑会清除正文块选区，避免复制/剪切被正文抢占。长标题自动换行显示。
