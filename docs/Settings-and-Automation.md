# 设置、备份与应用控制

## 工作空间

点击侧边栏顶部的工作空间名称，可以快速切换，或打开“管理工作空间…”。设置 → 存储与备份也提供管理入口。

- 新增：填写名称、简介，选择图标和颜色；创建后自动进入新空间。
- 编辑：修改名称、简介、图标和颜色，保存后即时生效。名称去除首尾空白，限 1–60 字符且不能重名；简介最多 500 字符。
- 切换：先保存当前待写入正文，再加载目标空间；编辑器、页面列表、搜索、回收箱和 MCP 随之切换。助手旧操作预览失效，需要重新生成。
- 删除：确认后将整个独立空间文件夹移入当前存储目录内隐藏的 `.Trash` 应用回收目录，并从正常空间列表隐藏；名称、页面、资源及目录内文件保留。左侧回收箱统一提供单项恢复/删除、全部恢复和全部删除，管理弹窗不再重复放置回收箱。只有永久删除/清空才真正移除文件夹。全部删除会创建新的空白空间供继续使用，原空间均可恢复。提交失败恢复原目录与连接，真实共享目录仍受保护。
- 数据隔离：每个空间使用独立 SQLite 数据库。首次升级将旧数据库复制到独立的 `Workspaces/<UUID>/velora.sqlite`，原文件保留；新空间使用相同布局，每个文件夹还保存 `workspace.json`，用于移动文件夹后的名称/图标恢复。
- 持久化：空间配置和上次使用空间记录在应用支持目录 `Velora/workspaces.json`，原子写入。切换失败时保留当前空间；不会为丢失的目标数据库创建空库。
- “更改位置”统一迁移所有工作空间，使用一致性快照；全部成功后再切换目录配置，保留源文件；目标若存在同 ID 的旧文件夹，则分配新的独立文件夹，不覆盖或打开旧副本。重复选择当前目录不会再创建副本。新建和备份恢复的空间共用该目录，不提供单空间存储位置设置。选择目标目录时自动登记其 Workspaces 下的直接子空间，读取 workspace.json 保留名称；同 ID 的旧迁移副本与已删除空间不重复登记。非当前空间的缺失数据库保留为可恢复记录，不阻止可用空间迁移。
- 备份文件名使用 `Velora-All-时间-随机后缀.zip`，统一记录全量备份时间；在所选备份目录下自动创建 `backup` 子目录。备份目录、自动备份开关、AI/MCP/语音和外观配置为应用级共享设置。

## 页面移动

- 拖到页面上：成为它的子页面，目标自动展开。
- 子页面行的向左上箭头：移出一级；页面菜单也提供同名操作。
- 拖到侧边栏底部“拖到这里移出到顶层”：成为顶层页面。
- 上移/下移控制同级顺序；“移动到…”可搜索目标。
- 移动自己或移动到后代会被拒绝。

代码块顶部保留语言、行数、复制、折叠；删除或转为正文通过代码卡片右键菜单。

## 图片来源

输入 `/图片` 或把块类型改成“图片”，点击“选择图片…”，选择“图片 URL”或“本地文件”。图片 URL 应为可访问的图片直链，推荐 HTTPS。

本地图片最大 12 MB，保存时把副本嵌入页面数据库，原文件改名或移动后仍可查看，数据库快照备份和空间迁移均包含图片。PNG/JPEG/GIF/WebP 保留原数据，其他系统可识别格式转为 PNG；预览使用缩略图。

图片生成结果若由服务商返回远程 URL，插入页面时会下载并保存图片副本；如果下载失败，保留预览并显示原因，不插入无效图片。手动选择的 URL 图片保留远程链接，其可用性取决于图片源。

## 设置入口

侧边栏底部“设置”，或 macOS 菜单 Velora → 设置（⌘,）。

- 外观与编辑：界面语言（跟随系统 / 简体中文 / English）、系统/浅色/深色、强调色、正文和代码字号、代码行号。语言即时切换并持久化，不翻译或修改已存文档。主要界面、块类型/菜单、预览代码复制按钮与操作提示共用本地翻译资源。
- 存储与备份：选择存储文件夹会先保存正文，再通过 SQLite online backup 创建一致性副本并打开新的数据库连接。原文件保留；新位置已有同 ID 文件夹时使用新文件夹保存当前快照。设置显示实际的 `Workspaces` 目录，迁移错误直接显示在位置按钮旁。
- 备份：手动备份、运行期间每日自动备份，均生成 `.zip` 压缩文件。启动后每分钟检查一次，到期备份；应用未运行时不会执行。历史备份不自动清理。
- 全量 ZIP 包含 `manifest.json`（版本 2、当前空间、全部空间信息和各数据库 SHA-256）及 `Workspaces/<UUID>/velora.sqlite`。包含所有已登记空间，以及仍保留数据库的已删除空间。先保存当前正文，再为各数据库生成包含 WAL 的一致性快照；页面树、块格式、回收箱、内嵌图片和 PDF 一同打包，无需 WAL 辅助文件。任一正常空间缺失或备份失败时，不生成不完整的成功备份。
- 点击“从 ZIP 备份恢复…”，选取 Velora 备份。恢复时验证 ZIP CRC、清单版本、SHA-256、SQLite 完整性、表结构与外键；全部通过后一次性登记恢复出的所有空间，并切换到备份时的当前空间。原工作空间及其数据不会被覆盖，同名恢复空间自动添加编号。无效备份不会改变当前工作空间。
- 压缩包及解压后内容均限 512 MB。包内文件通过内存读取，不按任意路径解压。备份不包含外部链接指向的文件、UserDefaults 偏好、模型配置和钥匙串密钥。兼容旧版单空间 ZIP；已有工作空间通过选择统一存储目录自动加载，“管理工作空间”提供独立导入入口。名称优先使用 workspace.json 或已有清单中的名称，缺失名称且文件夹为 UUID 时显示“导入的工作空间”，重名自动编号。
- 中英文资源位于 `App/en.lproj/Localizable.strings` 和 `App/zh-Hans.lproj/Localizable.strings`；显示文案通过 `L10n` 读取，块类型原始值和协议字段保持稳定。

## AI 助手

设置 → AI 助手中启用 AI，并通过“新增模型”保存多个配置。每个配置包含名称、服务商、用途、基础地址或完整接口 URL、模型 ID 和独立密钥；语音朗读还包含音色 ID。

支持五类用途，可分别选择默认模型：

| 用途 | 兼容接口 | 输入与结果 |
| --- | --- | --- |
| 文字对话 | `/v1/chat/completions` | 文字问答、原有助手操作预览 |
| 图片理解 | `/v1/chat/completions` | 文字与一张 URL / 本地图片，返回文字 |
| 语音转文字 | `/v1/audio/transcriptions` | 本地音频文件，返回可编辑/复制的文字 |
| 图片生成 | `/v1/images/generations` | 文字描述，返回图片预览 |
| 语音朗读 | `/v1/audio/speech` | 文字与音色，返回可播放、停止、保存的 MP3 |

使用 OpenAI 兼容协议，可接入提供对应协议的通义千问、DeepSeek、OpenAI、本机模型服务或网关；模型能力由服务商决定，不代表所有模型都支持所有用途。原生 Anthropic、Gemini 等非兼容协议需经兼容网关接入。

远程服务使用 HTTPS，本机 localhost / 127.0.0.1 / ::1 可使用 HTTP。仅填写主机地址会补全 `/v1/<用途路径>`；以 `/v1` 结尾的基础地址会补全对应路径；自定义完整地址保留原路径及查询参数。
密钥随保存配置写入 macOS 钥匙串，不写入模型配置。原有单模型设置自动登记为“原有模型”，继续使用原有钥匙串密钥。
“编辑 / 测试”可发送测试文字、所选图片/音频，或生成测试图片/语音；测试显示进度、模型回复或错误。测试使用当前表单，取消表单不会保存配置。生成类接口可能产生服务商费用。

助手面板中的“多模态工具…”支持五类任务。发送前选择模型和输入，只有当前输入及明确选中的附件会发送，不自动发送页面内容。生成结果先预览，可手动插入当前页面；语音显示 AI 生成标识，支持播放、停止与保存。原有 Apple 麦克风识别仍可在语音操作中启用；云端转写在多模态工具中选择音频文件。

语音文件最大 25 MB，支持 MP3/M4A/WAV/WebM/OGG/FLAC 等常见格式。朗读文字为 1–4096 字符；服务商可能有额外限制。取消请求或切换工作空间会取消待处理请求，清除当前结果，不自动执行页面操作。

主窗口工具栏的闪光图标或 ⌘J 打开助手。
指令 → 生成预览 → 核对操作、目标页面和正文 → 执行。
支持新建、打开、重命名、移动、移入回收箱、恢复、追加正文，不支持永久删除。
多项操作依次执行，失败时停止后续操作并报告已完成数量；不是跨操作事务。

默认 AI 上下文含当前指令、活跃页面标题/UUID/层级、当前页 UUID。
只有开启“将当前页面正文加入 AI 上下文”时才加入当前页最多 30,000 字符；图片块以占位文字表示，不自动上传图片。
页面数据按不可信上下文处理；模型输出只有白名单操作可以执行，且必须先在界面确认。

不依赖 AI 的指令示例：

```text
新建页面 会议记录
打开 项目计划
移出当前页面
立即备份
切换深色主题
切换浅色主题
跟随系统主题
```

“打开”要求标题精确且唯一。模糊、复杂指令走用户配置的 AI 服务。

## 本机 MCP

启用后监听 `http://127.0.0.1:18427/mcp`（端口可改）。关闭时不开放服务。
实现 sessionless Streamable HTTP，以 JSON 响应；不提供 SSE 推送，GET 返回 405。
支持 initialize、ping、tools/list、tools/call，支持协议版本 2025-03-26 / 2025-06-18 / 2025-11-25。
只绑定回环地址，要求 Bearer 令牌，并验证 Origin；请求有大小、并发连接与超时限制。

点击“复制连接配置”，将配置导入支持 HTTP MCP 的客户端。格式示意（真实令牌从应用复制，不写入仓库）：

```json
{
  "mcpServers": {
    "velora": {
      "type": "http",
      "url": "http://127.0.0.1:18427/mcp",
      "headers": { "Authorization": "Bearer <在应用中生成的令牌>" }
    }
  }
}
```

不同客户端字段可能不同；要点是 URL、Streamable HTTP 和 Authorization 头。
默认只读工具：`list_pages`、`read_page`。
显式开启“允许外部客户端修改页面”后额外开放：`create_page`、`rename_page`、`move_page`、`trash_page`、`restore_page`、`append_text`、`open_page`。
所有参数都是字符串，页面使用 UUID；`parent_id` 为空表示顶层。
MCP 写入在允许写入后直接执行，不走内置助手预览；请在客户端管理工具审批。
更改读写权限后客户端需重新连接/获取工具列表。更新令牌后旧配置失效。
当前实现的是让外部 MCP 客户端控制 Velora，不是 Velora 连接任意外部 MCP 服务器。

## 语音

设置中启用语音操作，选择语言后，在助手面板点击麦克风。
首次使用请求麦克风与语音识别权限，不会在应用启动时申请或后台监听。
点击结束或约 55 秒后结束录音，结果可编辑；仍需生成预览、确认执行。
默认仅设备识别；设备/语言不支持时明确提示，不自动改用云端。
用户关闭仅设备识别后，系统语音识别可能联网处理音频。
语音无须 API 密钥；识别后的复杂指令需要用户配置 AI，简单本地指令则不需要。

## 多模态兼容协议参考

请求格式依据官方 API 文档：[Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[图片生成](https://developers.openai.com/api/reference/resources/images/methods/generate)、[语音转写](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create)。第三方服务兼容范围以其文档为准。

- “管理工作空间”弹窗提供“导入工作空间”：选择文件夹、总目录或 SQLite 文件后，预览同 ID、同名、同文件路径冲突，提供“保留 / 跳过 / 替换”。保留另建副本，跳过不改已有数据，替换沿用已有空间 ID，将原数据库登记为“替换前”可恢复记录；所有提交失败一起回滚。备份区保持全量 ZIP 备份与恢复，不放独立导入按钮。
- 文件夹被移动后，可重新选择包含原空间的目录（例如 Workspaces2），按 workspace.json 的 ID 及原文件夹名重新连接，支持启动失败页选择新目录。目录路径会持久化，新建和恢复空间继续写入所选目录。

- 工作空间菜单和管理弹窗提供“刷新工作空间”：批量登记手动移入当前存储目录的空间，保留名称和当前编辑状态，重复刷新不重复添加。手动刷新可重新显示目录中保留的已移除空间，但不显示替换前归档。导入选择器支持单选、多选文件夹/SQLite 文件，并对重叠选区按源路径去重，仍提供三种重复策略。

- 回收箱同时显示工作空间与当前空间文档。文档支持单项删除/恢复/永久删除、全部文档移入回收箱、全部恢复与清空；清空删除页面、块及内嵌资源记录，不删除外部链接指向的原文件。备份与存储迁移保留工作空间回收箱；刷新不会重新登记回收箱中的空间。
- 正文与代码字号滑杆统一使用 11–22 pt、1 pt 步长，以保持刻度一致。

- 管理弹窗采用紧凑单行操作栏；全部删除放在更多菜单。回收箱顶栏仅显示“全部恢复”和“全部删除”，每项显示“恢复”“删除”，永久删除保留确认。
- 已登记的独立 UUID 后缀目录在启动时直接使用，不再复制为标准 UUID 目录。刷新/迁移后将未登记的同 ID 历史副本归档到存储总目录外 backup/WorkspaceCopies-*，保留所有历史文件；删除时将同 ID 遗留副本收进该空间回收目录，永久删除整个回收目录。
