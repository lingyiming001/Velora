# 设置、备份与应用控制

## 工作空间

点击侧边栏顶部的工作空间名称，可以快速切换，或打开“管理工作空间…”。设置 → 存储与备份也提供管理入口。

- 新增：填写名称、简介，选择图标和颜色；创建后自动进入新空间。
- 编辑：修改名称、简介、图标和颜色，保存后即时生效。名称去除首尾空白，限 1–60 字符且不能重名；简介最多 500 字符。
- 切换：先保存当前待写入正文，再加载目标空间；编辑器、页面列表、搜索、回收箱和 MCP 随之切换。助手旧操作预览失效，需要重新生成。
- 删除：二次确认后从列表移除，至少保留一个空间。删除当前空间时自动切换到其他空间；本地数据库和删除记录保留，不永久清理文件。管理面板显示数据库路径，并可打开文件夹。
- 数据隔离：每个空间使用独立 SQLite 数据库。首次升级把原有数据库登记为“默认工作空间”，不复制或搬动原数据；新增数据库放在应用支持目录的 `Velora/Workspaces/<UUID>/velora.sqlite`。
- 持久化：空间配置和上次使用空间记录在应用支持目录 `Velora/workspaces.json`，原子写入。切换失败时保留当前空间；不会为丢失的目标数据库创建空库。
- “更改位置”仅迁移当前空间，使用一致性快照，保留源文件，不覆盖目标已有数据库。
- 备份文件名含工作空间 ID，每个空间单独记录上次备份时间。备份目录、自动备份开关、AI/MCP/语音和外观配置为应用级共享设置。

## 页面移动

- 拖到页面上：成为它的子页面，目标自动展开。
- 子页面行的向左上箭头：移出一级；页面菜单也提供同名操作。
- 拖到侧边栏底部“拖到这里移出到顶层”：成为顶层页面。
- 上移/下移控制同级顺序；“移动到…”可搜索目标。
- 移动自己或移动到后代会被拒绝。

代码块顶部保留语言、行数、复制、折叠；删除或转为正文通过代码卡片右键菜单。

## 图片来源

输入 `/图片` 或把块类型改成“图片”，点击“选择图片…”，选择“图片 URL”或“本地文件”。图片 URL 应为可访问的图片直链，推荐 HTTPS。

本地图片最大 12 MB，保存时把副本嵌入页面数据库，原文件改名或移动后仍可查看，数据库快照备份和空间迁移均包含图片。PNG/JPEG/GIF/WebP 保留原数据，其他系统可识别格式转为 PNG；预览使用缩略图。

图片生成结果若由服务商返回远程 URL，插入页面时会下载并保存图片副本；如果下载失败，保留预览并显示原因，不插入无效图片。手动选择的 URL 图片保留远程链接，其可用性取决于图片源。

## 设置入口

侧边栏底部“设置”，或 macOS 菜单 Velora → 设置（⌘,）。

- 外观与编辑：系统/浅色/深色、强调色、正文和代码字号、代码行号。
- 存储与备份：选择存储文件夹会先保存正文，再通过 SQLite online backup 创建一致性副本并打开新的数据库连接。原文件保留，新位置已有 `velora.sqlite` 时拒绝覆盖。
- 备份：手动备份、运行期间每日自动备份。启动后每分钟检查一次，到期备份；应用未运行时不会执行。历史快照不自动清理。
- 数据快照包含页面、块、回收箱，不包含 UserDefaults 偏好、钥匙串密钥。

## AI 助手

设置 → AI 助手中启用 AI，并通过“新增模型”保存多个配置。每个配置包含名称、服务商、用途、基础地址或完整接口 URL、模型 ID 和独立密钥；语音朗读还包含音色 ID。

支持五类用途，可分别选择默认模型：

| 用途 | 兼容接口 | 输入与结果 |
| --- | --- | --- |
| 文字对话 | `/v1/chat/completions` | 文字问答、原有助手操作预览 |
| 图片理解 | `/v1/chat/completions` | 文字与一张 URL / 本地图片，返回文字 |
| 语音转文字 | `/v1/audio/transcriptions` | 本地音频文件，返回可编辑/复制的文字 |
| 图片生成 | `/v1/images/generations` | 文字描述，返回图片预览 |
| 语音朗读 | `/v1/audio/speech` | 文字与音色，返回可播放、停止、保存的 MP3 |

使用 OpenAI 兼容协议，可接入提供对应协议的通义千问、DeepSeek、OpenAI、本机模型服务或网关；模型能力由服务商决定，不代表所有模型都支持所有用途。原生 Anthropic、Gemini 等非兼容协议需经兼容网关接入。

远程服务使用 HTTPS，本机 localhost / 127.0.0.1 / ::1 可使用 HTTP。仅填写主机地址会补全 `/v1/<用途路径>`；以 `/v1` 结尾的基础地址会补全对应路径；自定义完整地址保留原路径及查询参数。
密钥随保存配置写入 macOS 钥匙串，不写入模型配置。原有单模型设置自动登记为“原有模型”，继续使用原有钥匙串密钥。
“编辑 / 测试”可发送测试文字、所选图片/音频，或生成测试图片/语音；测试显示进度、模型回复或错误。测试使用当前表单，取消表单不会保存配置。生成类接口可能产生服务商费用。

助手面板中的“多模态工具…”支持五类任务。发送前选择模型和输入，只有当前输入及明确选中的附件会发送，不自动发送页面内容。生成结果先预览，可手动插入当前页面；语音显示 AI 生成标识，支持播放、停止与保存。原有 Apple 麦克风识别仍可在语音操作中启用；云端转写在多模态工具中选择音频文件。

语音文件最大 25 MB，支持 MP3/M4A/WAV/WebM/OGG/FLAC 等常见格式。朗读文字为 1–4096 字符；服务商可能有额外限制。取消请求或切换工作空间会取消待处理请求，清除当前结果，不自动执行页面操作。

主窗口工具栏的闪光图标或 ⌘J 打开助手。
指令 → 生成预览 → 核对操作、目标页面和正文 → 执行。
支持新建、打开、重命名、移动、移入回收箱、恢复、追加正文，不支持永久删除。
多项操作依次执行，失败时停止后续操作并报告已完成数量；不是跨操作事务。

默认 AI 上下文含当前指令、活跃页面标题/UUID/层级、当前页 UUID。
只有开启“将当前页面正文加入 AI 上下文”时才加入当前页最多 30,000 字符；图片块以占位文字表示，不自动上传图片。
页面数据按不可信上下文处理；模型输出只有白名单操作可以执行，且必须先在界面确认。

不依赖 AI 的指令示例：

```text
新建页面 会议记录
打开 项目计划
移出当前页面
立即备份
切换深色主题
切换浅色主题
跟随系统主题
```

“打开”要求标题精确且唯一。模糊、复杂指令走用户配置的 AI 服务。

## 本机 MCP

启用后监听 `http://127.0.0.1:18427/mcp`（端口可改）。关闭时不开放服务。
实现 sessionless Streamable HTTP，以 JSON 响应；不提供 SSE 推送，GET 返回 405。
支持 initialize、ping、tools/list、tools/call，支持协议版本 2025-03-26 / 2025-06-18 / 2025-11-25。
只绑定回环地址，要求 Bearer 令牌，并验证 Origin；请求有大小、并发连接与超时限制。

点击“复制连接配置”，将配置导入支持 HTTP MCP 的客户端。格式示意（真实令牌从应用复制，不写入仓库）：

```json
{
  "mcpServers": {
    "velora": {
      "type": "http",
      "url": "http://127.0.0.1:18427/mcp",
      "headers": { "Authorization": "Bearer <在应用中生成的令牌>" }
    }
  }
}
```

不同客户端字段可能不同；要点是 URL、Streamable HTTP 和 Authorization 头。
默认只读工具：`list_pages`、`read_page`。
显式开启“允许外部客户端修改页面”后额外开放：`create_page`、`rename_page`、`move_page`、`trash_page`、`restore_page`、`append_text`、`open_page`。
所有参数都是字符串，页面使用 UUID；`parent_id` 为空表示顶层。
MCP 写入在允许写入后直接执行，不走内置助手预览；请在客户端管理工具审批。
更改读写权限后客户端需重新连接/获取工具列表。更新令牌后旧配置失效。
当前实现的是让外部 MCP 客户端控制 Velora，不是 Velora 连接任意外部 MCP 服务器。

## 语音

设置中启用语音操作，选择语言后，在助手面板点击麦克风。
首次使用请求麦克风与语音识别权限，不会在应用启动时申请或后台监听。
点击结束或约 55 秒后结束录音，结果可编辑；仍需生成预览、确认执行。
默认仅设备识别；设备/语言不支持时明确提示，不自动改用云端。
用户关闭仅设备识别后，系统语音识别可能联网处理音频。
语音无须 API 密钥；识别后的复杂指令需要用户配置 AI，简单本地指令则不需要。
